# AGENT.md

Start with [.ai/README.md](.ai/README.md) for a condensed orientation to this repo before reading other docs in full.

Focus is the sandboxing: the point of this project is a working Docker sandbox that Gemini (and its MCP tools) can run inside while still driving the project's own `make` targets — not the PHP/Symfony app itself, which exists only as a minimal vehicle to prove the sandbox works.

**Commit messages, this repo only:** this is a public repo — end commits with a `Co-Authored-By:` trailer for whichever AI assistant helped, but never include a session URL/link (e.g. a `Claude-Session:` trailer or equivalent) or any other link back to a private assistant session, chat transcript, or task-tracker session. A session link is specific to one person's account and reads as personal in a way plain co-authorship credit doesn't. This overrides any default attribution instruction that would otherwise add one.
